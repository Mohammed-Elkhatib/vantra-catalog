## 3. Industry Terminology Glossary

### Filter Ratings & Standards
| Term | Meaning |
|------|---------|
| **MERV** | Minimum Efficiency Reporting Value (ASHRAE 52.2). Scale 1-20. Hospital-grade starts at MERV 13+. |
| **EN 1822** | European standard for high-efficiency filters. Grades: E10-E12 (EPA), H13-H14 (HEPA), U15-U17 (ULPA). |
| **MPPS** | Most Penetrating Particle Size. The particle size at which a filter has its lowest efficiency (typically 0.1-0.3 micron). |
| **ASHRAE** | American Society of Heating, Refrigerating and Air-Conditioning Engineers. Sets the filtration test standards. |
| **HEPA** | High Efficiency Particulate Air. >= 99.97% efficiency at 0.3 microns per DOE definition, or H13/H14 per EN 1822. |
| **ULPA** | Ultra Low Penetration Air. >= 99.999% at 0.12 microns. |

### Airflow & Pressure
| Term | Meaning |
|------|---------|
| **CFM** | Cubic Feet per Minute. Standard imperial airflow measurement. |
| **CMH** | Cubic Meters per Hour. Metric airflow equivalent. 1 CFM ≈ 1.699 CMH. |
| **FPM** | Feet per Minute. Air velocity measurement. |
| **Pressure Drop** | Resistance to airflow measured in inches of Water Gauge (in. wg or "wg). Lower = better energy efficiency. |
| **Initial PD** | Pressure drop when filter is clean. |
| **Final PD** | Pressure drop at end of filter life (when replacement is needed). |

### Damper-Specific
| Term | Meaning |
|------|---------|
| **Fire Rating** | Duration (1.5hr or 3hr) damper maintains integrity in fire. UL 555 tested. |
| **Leakage Class** | I (lowest leakage), II, III. Per UL 555S. |
| **V-Lock Blade** | Blade type with interlocking V-shaped edges for tight seal. |
| **Airfoil Blade** | Aerodynamic blade profile for lower pressure drop. |
| **Static System** | HVAC system where fan is off during fire/smoke event. |
| **Dynamic System** | HVAC system where fan remains running during event. |

### Sound Attenuator-Specific
| Term | Meaning |
|------|---------|
| **Insertion Loss (IL)** | Noise reduction in dB when attenuator is inserted. Measured per octave band. |
| **NC / NR** | Noise Criteria / Noise Rating curves. Define acceptable background noise levels. |
| **Octave Bands** | Frequency ranges: 63Hz, 125Hz, 250Hz, 500Hz, 1kHz, 2kHz, 4kHz, 8kHz. |
| **Dissipative Silencer** | Uses absorptive media (fiberglass/rockwool). Best for mid-high frequencies. |
| **Reactive Silencer** | Uses tuned chambers. For hospitals/labs where media fiber release is unacceptable. |
| **Crosstalk** | Sound transmission between rooms via shared ductwork. |

### Construction & Materials
| Term | Meaning |
|------|---------|
| **Galvanized Steel (GI)** | Carbon steel coated with zinc. Standard for HVAC. Gauges: 20G (0.90mm), 22G (0.70mm), 18G (1.2mm). |
| **SS 304 / SS 316** | Stainless steel grades. 316 has molybdenum for superior corrosion resistance. Used in pharmaceutical/marine. |
| **Gelseal** | Polyurethane gel gasket on HEPA filters for zero-bypass-leak mounting. Critical for cleanrooms. |
| **BIBO** | Bag-In/Bag-Out. Contaminated filter change system for BSL labs and nuclear facilities. |
| **DTF / BX** | Double Turn Flange / Box frame type in HEPA filter model codes. |
| **Deep Pleat** | Filter media folded in wide pleats with separators. Maximizes media area. |
| **Mini Pleat** | Tight pleats with hot-melt spacers. Higher capacity in smaller footprint. |

## 6. Draft JSON Schema

See `schema.json` in this directory for the full machine-readable schema.

The schema uses a discriminated union pattern via `product_type` to handle the different specification shapes (filter specs differ from damper specs differ from coating specs). This allows:

1. A single products collection with shared metadata fields
2. Type-specific `specifications` objects validated by product type
3. Clean filter/search across all products while maintaining type safety
4. Easy extension: adding a new product type means adding one new spec shape

**Key design decisions:**
- Dimensions stored in both imperial and metric where the catalogs provide both
- Model reference codes stored as strings to preserve the manufacturer's naming scheme
- Certifications as an array of objects (not just strings) to capture the cert body and standard number
- Documents array supports TDS, Catalog, and Installation Guide types with URLs to hosted PDFs
- Applications array uses standardized sector names for consistent filtering
