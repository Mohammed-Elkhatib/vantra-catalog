search did not turn up domain-true, non-generic stock photos for duct silencers or canvas

stock contributors). Per spec §7's fallback, these tiles render the existing rule-tinted CSS
placeholder block (`CategoryTile` with `imageSrc` omitted) rather than force a mismatched photo.
